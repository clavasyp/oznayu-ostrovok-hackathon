## Как интерфейс попадает в образ

Docker собирает его сам (`Dockerfile`, стадия `ui`, Node 24 LTS), если в этой папке есть `package.json`:

- `npm ci`, если рядом есть `package-lock.json` (лучше закоммитить его — тогда версии зафиксированы); иначе `npm install`;
- затем `npm run build` — результат должен лечь в `ui/dist/` (`index.html` + файлы), как у Vite по умолчанию.

FastAPI отдаёт `ui/dist` на `/`. Любой путь вне `/api` без своего файла получает `index.html`, поэтому маршруты на стороне браузера (React Router) работают и при обновлении страницы.

API — тот же адрес, относительные пути `/api/...`. Для `npm run dev` (Vite на 5173) API на 8080 уже разрешает CORS с `http://localhost:5173`. Можно вместо этого настроить в Vite `server.proxy` на `http://localhost:8080`.

Пока `package.json` нет, на `/` открывается временная страница со ссылками на API.
