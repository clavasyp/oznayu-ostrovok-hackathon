# packs/

Пакеты городов: результаты расчётов и manifest.json — грузятся при старте.

Владелец: Сева. Изменения в чужой папке — через PR владельца.

Сейчас здесь 8 городов. Москва и Большой Сочи — полный каталог Островка с георасчётами, корпусами, фасадами, местами и станциями (сборщики `pipeline/build_packs.py` → `finalize_packs.py` → `supplement_categories.py`, публикация `publish_packs.py`). Остальные 6 — автоматический слой из расчётов v9 (Codex): `python -m pipeline.build_v9_packs --city …` пересобирает их из `research_notes/Расчёт характеристик/`; пакет другой сборки он не перезаписывает. Сборки детерминированные — без изменений входа пакет не меняется. После пересборки — `make audit` и `make test-packs`.
