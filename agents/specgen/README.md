# agents/specgen/

Новая характеристика из текста (core.md §7.4, задача 4): текст админа → черновик спецификации
(YAML, core.md §3) → проверка → пробный расчёт на 20 отелях → включает человек.

**Включение — не здесь.** Черновик никуда не сохраняется. Статус `active`, файл в `specs/` и
таблица `feature` — у лида; расчёт — у владельца калькулятора.

## Что где

| Файл | Что |
|---|---|
| `spec.py` | Спецификация по core.md §3 (pydantic): поля значения, поиск, рецепты, `ttl_days`, `status: draft`. YAML туда и обратно — без потерь |
| `registry.py` | Что можно использовать: слои данных (WorldCover с классами, OSM, рельеф, GTFS) и калькуляторы с параметрами, слоями и единицей. Зарегистрирован ли калькулятор — по реестру плагинов `core.plugins` |
| `draft.py` | Текст → черновик. Правила: «доля застройки / леса / воды… в N м / км» → доля классов WorldCover. Остальное — модель по компактной схеме; она видит только реестр и каталог |
| `validate.py` | Проверка: калькулятор и слои существуют, версия, уровень и единица сходятся, параметры допустимы (коды WorldCover, радиус 100–2000 м), поиск ссылается на поле значения, такой характеристики ещё нет |
| `trial.py` | Пробный расчёт: калькулятор из реестра на первых 20 отелях города → покрытие, причины «неизвестно», примеры. Факты не сохраняются |
| `__main__.py` | `python -m agents.specgen "доля застройки в 300 м" [--trial --city sochi] [--llm]` |

API для формы админа — `POST /api/specs/draft` и `POST /api/specs/trial` (`app/api/specs.py`).

## Пример: «доля застройки в 300 м»

```yaml
id: built_up_share_300m
title: Доля застройки в радиусе 300 м
subject_level: hotel
value:
  share_pct: {type: number, unit: '%'}
recipes:
- id: built_up_share_300m-R1
  kind: computed
  calculator: env.landcover_share@1
  params: {classes: [50], radius_m: 300}
  requires: {layers: [worldcover]}
```

Калькулятор `env.landcover_share` — у Леры (`calculators/env_landcover.py`): доля классов
WorldCover в радиусе, как E03, но с параметрами `classes` и `radius_m`. Знаменатель — суша; если
среди классов есть вода (80) — вся размеченная площадь круга. Без тайла, за краем вырезки
`data/worldcover` и без геобиблиотек (в образе приложения их нет) пробный расчёт отвечает
«неизвестно» с причиной, а не падает. Пока калькулятора нет в реестре, черновик проходит
проверку с замечанием, а пробный расчёт отвечает «калькулятор ещё не зарегистрирован».

## Что ловит проверка

- «доля зелени в 300 м» — это уже E03: повтор характеристики, которую считает калькулятор
  с фиксированными параметрами;
- калькулятор или слой, которых нет в реестре (модель не может их придумать);
- единица калькулятора не совпала с полем значения, другой уровень (номер вместо отеля);
- коды WorldCover вне списка, радиус вне 100–2000 м, лишние параметры;
- вопрос отельеру без текста или без полей ответа.
