| D33 | 2026-10-24 | **Четвёртый вид данных — ручная обработка командой с ИИ** (`curated`, «проверено командой»): то, что автоматика не собирает и алгоритм не считает, а человек с помощью LLM, скриптов и Codex обрабатывает разово по городу (D6).
Примеры: сопоставление отель ↔ здание при неуверенности; входы на пляж и покрытие пляжа; проверка вида по уличным фото; извлечение из текстов Островка; стройки и события; черновая привязка категорий к сторонам здания.

**Правила:**
- результат нейронки или Codex без проверки человеком — **кандидат** (`curation_item`), а не факт (D8);
- факт `curated` появляется только после «принято» или «исправлено» человеком, с именем проверяющего и доказательствами (ссылка или файл + хеш, цитата или область);
- в обязательных условиях — только при доказательстве из первоисточника того же смысла;
- расхождение с расчётом или отельером → `conflict`;
- у связей (отель ↔ здание, категория ↔ сторона) — то же происхождение: авто или проверено командой;
- процесс по каждому виду обработки описан в README (требование эксперта: «объясните процесс получения»).

**Уточнение 24.10 (пользователь):** ручная работа — это прежде всего **добыча** новых данных под пробелы, а не только проверка наших. Например, расписания транспорта, рестораны и их кухня с многих сайтов, PDF и сканы, городские порталы.
