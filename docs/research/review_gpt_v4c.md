## Бейджи: три оси в интерфейсе

Enum в базе не меняется. Интерфейс показывает три оси:
- **соответствие запросу:** выполнено / не выполнено / нужно проверить;
- **способ получения:** вычислено / источник / отельер;
- **ограничения:** оценка, конфликт, срок, область.

Процентов уверенности до собственной калибровки не показываем.

| Статус | Текст | Пояснение | Цвет (текст / фон) |
|---|---|---|---|
| подтверждено | «Подтверждено» | «Проверено по […]. Относится к […]. Наблюдение [дата]» | #166534 / #DCFCE7 |
| вычислено | «Вычислено» | «По [входы], алгоритм [версия], расчёт [дата]. Ограничения: …» | #1D4ED8 / #DBEAFE |
| оценка | «Оценка» | «Примерно [диапазон]. [Причина]. Не подтверждает обязательное условие» | #854D0E / #FEF9C3 |
| со слов отельера | «Со слов отельера» | «Ответ [кто], [дата]. Для [категория / этажи / исключения]» | #6B21A8 / #F3E8FF |
| **данные Островка** | **«Данные Островка» — добавить**, с датой снимка страницы | Каталог, категории, правила, реестр | выбрать отдельный цвет |
| неизвестно | «Нет данных» + «Нужно уточнить» | Что именно неизвестно + кнопка «Вопрос отельеру». Не писать «скорее всего» | #374151 / #F3F4F6 |
| противоречие | «Источники расходятся» | Обе версии с датами; обязательное условие не проходит | #991B1B / #FEE2E2 |
| имитация | «Имитированный ответ» | Метка сохраняется на ответе, фактах и выдаче | #7E22CE / #FAF5FF — нужна своя иконка |

**Дополнительные статусы:**
- «Нужно перепроверить» — срок истёк. Цвет развести с «Оценкой».
- «Не применимо» — не путать с «нет данных».

**Что видно сразу:**
- 2–3 значимых совпадения и компромисс;
- блокирующие пробелы, конфликты и оценки;
- область обещания.

Полный паспорт открывается по кнопке «Источник и ограничения». По WCAG смысл не передаётся только цветом, контраст текста ≥ 4,5:1 (в отчёте контраст не проверен).

## Экраны

1. **Поиск:**
   - текст, город, даты, время приезда, гости, питомец, требования к передвижению;
   - пресеты пяти персон;
   - экран «Я понял: …» с редактируемыми «Обязательно» и «Желательно»;
   - 1–2 уточняющих вопроса за раз;
   - отдельные состояния ошибки LLM и офлайн-режима.
2. **Выдача и карта:**
   - список и карта синхронны, список работает без WebGL;
   - счётчики «Подходят» и «Нужно уточнить»;
   - цены не показываем без источника.
3. **Карточка отеля:**
   - уровни «отель → здание → сторона и этаж → категория»;
   - таблица размещений «корпус + этаж + окна» с полнотой и уровнем гарантии;
   - конфликт показывает две версии рядом;
   - 17 семейств: релевантные раскрыты, остальные свёрнуты.
4. **Сравнение:**
   - 2–5 категорий, закреплённые обязательные условия, режим «только различия»;
   - «Нет», «Нет данных», «Оценка», «Не применимо» различаются;
   - нет общего процента и «победителя».
5. **Кабинет отельера:**
   - предзаполненная анкета с кнопками «Верно / Исправить / Различается / Не знаю»;
   - перед сохранением — «Из вашего ответа получились поля…»;
   - вопрос «Есть ли номера вне таблицы?»;
   - метка имитации.
6. **Админка:**
   - матрица 8 городов × 17 семейств с `n/N`;
   - слои города с лицензиями и версиями;
   - очередь конфликтов;
   - мастер «характеристика из текста»: черновик → проверка → пробный расчёт → покрытие → `active`.

## Карта

- **Выбор:** MapLibre GL JS (BSD-3) + собственные региональные PMTiles (Protomaps из выгрузки OSM; код BSD-3, дизайн CC0, тайлы ODbL).
- **Всё раздаётся с localhost:** стиль, шрифты, спрайты.
- **Атрибуция OSM** видна на карте и в видео.
- **Проверить:** кириллицу, турецкие и арабские подписи, ответ 206 на Range-запросы, работу без внешней сети.
- **Отклонены:** Google Tiles (офлайн запрещён), Яндекс (кеш ≤ 30 дней), 2ГИС (договор), публичные тайлы OSM.
