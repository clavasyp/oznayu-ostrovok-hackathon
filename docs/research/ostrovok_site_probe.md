# Данные Островка: ETG API и сайт ostrovok.ru (проба Claude, 23.10.2026)

> ⚠ **Поправка 23.10.2026 по выборке v5 (450 отелей в 9 городах, пересчитано Claude) — проба ниже обобщала 3 страницы и завысила заполненность.** Реальные цифры:
> - **Этажность** `floorsNumber > 0` — 9% отелей (у гостиниц 12,5%, в РФ 1–4 из 50 на город). **Год постройки** — 9%.
> - **Номер в реестре** — 21% российских объектов (27% гостиничного типа). `starCertificate` = тот же номер реестра.
> - **`roomGroups`** — у 58% отелей; `rg_ext` на сайте нет.
> - **Вид:** только флаг `with-view` без направления, чаще вид упоминается в названии категории.
> - **Питомцы:** структурированный блок у 5%, основной сигнал — текст удобств.
> - **Отзывы:** не больше 10 на страницу, полный корпус не найден.
> - **Sitemap:** ~25% URL устарели, выдача на сайте в 5–17 раз больше sitemap.
> - Из 80 характеристик данные Островка покрывают **17 частично, 0 полностью**.
>
> Пример «Жемчужины» верен, но нетипичен. Подробно — `docs/research/review_gpt_v5.md`.


## ETG API — без договора недоступен

- [факт] «Before using the API, the relevant agreement must be signed.» — https://docs.emergingtravel.com/docs/overview/
- [факт] Sandbox-ключ выдаёт только API Support по запросу. Тестовые ключи ограничены тестовым отелем (hid 8473727). Самостоятельной регистрации нет. — https://docs.emergingtravel.com/docs/fundamentals/sandbox
- [вывод] Без помощи организаторов ETG API нам недоступен. Основной канал — сайт.

**Как вообще получают доступ к ETG API** (проверено 23.10.2026; официального чек-листа нет, шаги собраны из документации ETG, сайта RateHawk и описаний интеграторов):
1. **Стать партнёром ETG / RateHawk.** Регистрация на ratehawk.com. Партнёрские роли: аффилиаты, технологические провайдеры, турагентства / OTA, поставщики. На практике это компания с юрлицом. Требования к регистрации публично не описаны.
2. **Подписать API-соглашение** через партнёрский или API-отдел (менеджер по API-партнёрствам).
3. **Получить sandbox-ключ** в поддержке API.
   - Хост `api-sandbox.worldota.net`.
   - Ограничения: тестовый отель hid 8473727, язык только `en`, обычно до 5 или 1000 записей в ответе, не все методы доступны, платёжных сценариев нет.
   - Доступность контентных методов и дампов зависит от настроек ключа, документация этого не гарантирует.
4. **Пройти сертификацию:** проверяются сценарии бронирования, статуса и отмены.
5. **Получить боевые ключи** в разделе API настроек договора.

[вывод] ETG API рассчитан на бронирование. Нам нужен только контент, поэтому этот путь долгий и непропорциональный. Реалистичный вариант — попросить у организаторов (Островок входит в ETG) тестовый или контентный ключ либо готовый дамп отелей.

## Сайт ostrovok.ru — организаторы разрешили использовать и игнорировать robots.txt (со слов пользователя, 23.10.2026)

Островок сам ни API, ни выгрузок не даёт. Сайт — единственный канал данных Островка.

**Как перечислить каталог:**
- `robots.txt` указывает `Sitemap: https://ostrovok.ru/sitemap.xml` — индекс из 56 частей, каждая ~7 МБ.
- Страницы отелей: `https://ostrovok.ru/hotel/{страна}/{город}/mid{ID}/{slug}/`, есть и AMP-версии `/amp/vhotel/...`.
- Например, в `sitemap_30.xml` 3 558 URL Сочи: отели, гостевые дома и квартиры.
- `robots.txt` закрывает выдачу (`/hotels*`), отзывы (`*/otzyvy/`), личные разделы. **Организаторы разрешили его игнорировать**: отзывы и выдача нам доступны. Личные разделы (`/accounts/`, `/orders*`) нам не нужны.

**Что на странице отеля.** Два источника структурированных данных:
1. **JSON-LD `Hotel`**: identifier, name, geo, address, amenityFeature, aggregateRating, priceRange.
2. **`__NEXT_DATA__`** (`props.pageProps.hotel`) — главный источник.

| Блок | Поля (проверено на 3 отелях: Батуми, Сочи-мини, Сочи «Жемчужина») |
|---|---|
| Идентификаторы | `id`, `masterId`, `location.regionId` |
| `facts` | `kind` (RESORT, MINI_HOTEL, GUESTHOUSE…), `starRating`, **`floorsNumber`**, `roomsNumber`, **`yearBuilt`**, `yearRenovated`, `hasHotelWifi`, `hasRoomWifi`, `electricity` (розетки, вольтаж) |
| **`facts.register`** (Россия) | **номер записи в реестре Росаккредитации, ссылка на tourism.fsa.gov.ru и число номеров по категориям реестра.** Пример «Жемчужина»: «С232024007508», 736 номеров CT_FIRST_STANDARD… |
| `starCertificate` | `certificateId`, `validTo` (пример: до 2028-08-08) |
| `location` | широта и долгота, адрес, город, **`pois`** (название, **расстояние в м**, тип: BEACH, CONCERTS_AND_PERFORMANCES…, `isTransportHub`), `nearestSubways` |
| `policies` | `checkInCheckOut` (часы), **`pets`** (включено или нет, цена, единица, тип животного), `children`, `cradle`, `extraBed`, `deposit`, `parking`, `shuttle`, `meal`, `internet`, `addFee` |
| `amenityGroups` | удобства отеля с `amenityId`, включая «Отсутствие лифтов», «Круглосуточная стойка» |
| **`roomGroups`** | категории: `nameStruct` (название, кровати, ванная), `size` м², **`roomAmenityData`** (`balcony`, `with-view`, `air-conditioning`, `private-entrance`…), `rgHash` |
| `rating`, `reviews` | рейтинг Островка, число отзывов, список части отзывов |
| Прочее | `images`, `descriptionStruct`, `serpFilters`, `specialFlags`, `contacts` |

**Пример «Гостиничный комплекс Жемчужина», Сочи:**
- 4★, 19 этажей, 881 номер, построен в 1973, реновация в 2007;
- запись в реестре ФСА;
- 15 категорий, из них 10 с балконом; «Люкс Морской»;
- пляж «Жемчужина» в 168 м, Зимний театр в 242 м.

## Что это даёт проекту

- **D19 решается через Островок:** у российских отелей номер в реестре и ссылка уже на странице. Доступ к API реестра не нужен.
- **Каталог отелей по городу** — из sitemap, с ID Островка как основным пространством имён `source_alias` (D24).
- **Этажность и год постройки здания отеля** — вход для расчёта вида и солнца, со статусом `ostrovok_content`.
- **Категории номеров** с балконом, видом, площадью, кроватями — основа `room_type`. Привязку к сторонам и этажам (`placement_set`) всё равно спрашиваем у отельера.
- **Сразу закрываются** из каталога 80 характеристик: питомцы (P01/P02 частично), поздний заезд (L04), кроватка (F03), кровати (M01), балкон (M02), часть доплат (M06), лифт.
- **POI с расстояниями** — сверка и ориентир для наших пеших маршрутов. Расстояние у Островка, вероятно, по прямой; наш маршрут — по графу.

## Правила сбора

- **`robots.txt` можно игнорировать** — разрешение организаторов (со слов пользователя, 23.10.2026).
- **Сбор всё равно вежливый**, чтобы не нагружать сайт: около 1 запроса в секунду на поток, кэш, повтор только после паузы, понятный User-Agent команды.
- Авторизацию и CAPTCHA не обходим, личные разделы не трогаем. Если сайт начнёт блокировать, снижаем частоту и сообщаем организаторам.
- **Отзывы теперь доступны.** Используем при сборке как слабые сигналы и материал для эталона: упоминания вида, шума, лифта. Из них LLM извлекает факты со ссылкой на отзыв (D20). Как истина о физическом признаке отзывы не используются.
- **Пробный сбор не делали:** скачаны только `robots.txt`, индекс и 2 части sitemap, 4 страницы отелей.
