**Атомы вне каталога (`[вывод]`, предложение AST):**
- **две независимые оси:** соответствие каталогу (точно / частично / другой смысл / вне) и факт об объекте (известно / оценка / неизвестно / неприменимо). Точное соответствие без доказательства → `unknown`;

- **логика AND / OR / NOT — отдельным графом;** трёхзначная до корня: NOT unknown = unknown; true AND unknown = unknown; false AND unknown = false; true OR unknown = true;
- пустой список условий ≠ `WHERE TRUE`;
- компактный протокол для LLM: текстовые предикаты и плоские узлы, типы и ID назначает сервер (`architecture/query_ast_compact_protocol.json`);
