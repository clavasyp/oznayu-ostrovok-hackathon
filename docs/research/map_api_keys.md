# Ключи карт: Яндекс, 2ГИС, Google — какие API, где ключ, лимиты, цены, условия

Собрал Claude 25.10.2026 по официальным страницам (ссылки — у каждого факта). Повод: организаторы ответили на вопрос 9 — ключи карт команда берёт сама (D35).

## Что нам нужно от карт

1. **Места рядом** — «рядом место типа X»: категория, кухня, часы работы, рейтинг.
2. **Маршруты и время в пути** — «доехать до X»: пешком, на машине с пробками, общественным транспортом.

## Яндекс Карты

- **Нужные API:**
  - **API Поиска по организациям** — категория («тип деятельности»), адрес, часы работы, контакты, до 50 объектов на запрос. [факт, [продукт](https://yandex.ru/maps-api/products/geosearch-api)] О рейтингах и отзывах на странице не сказано.
  - **Получение деталей маршрута** (Router API) и **Матрица расстояний**. [факт, [тарифы](https://yandex.ru/maps-api/tariffs)]
- **Бесплатного тарифа у этих трёх API нет.** [факт, [тарифы](https://yandex.ru/maps-api/tariffs)]
  - Бесплатно при выполнении условий — только JavaScript API, Геокодер, Геосаджест, Static API, MapKit SDK.
  - У Поиска по организациям есть тестовый период — его включает менеджер. [факт, [продукт](https://yandex.ru/maps-api/products/geosearch-api)]
- **Цены:** годовая лицензия на 1 000 запросов в сутки.
  - Поиск по организациям — 195 000 ₽ (стандартная) или 226 200 ₽ (расширенная). [факт, [продукт](https://yandex.ru/maps-api/products/geosearch-api)]
  - Матрица расстояний и Router API — по 226 200 ₽. [факт, [тарифы](https://yandex.ru/maps-api/tariffs)]
  - Сверх лимита — 390 ₽ за каждые 1 000 запросов.
- **Как получить ключ:** регистрация в кабинете разработчика → продукт и тариф → пополнить лицевой счёт. [факт, [продукт](https://yandex.ru/maps-api/products/geosearch-api)]
- **Условия Поиска по организациям** [факт, [условия](https://yandex.ru/dev/tariffs/doc/ru/geosearch/terms/)]:
  - показывать результаты «строго на фоне карты «Яндекс Карты»» (п. 1.1, 1.2);
  - кешировать — до 30 дней и только для скорости (п. 2.1);
  - иначе — «не сохранять и не хранить результаты ответа» (п. 2.2).

## 2ГИС

- **Нужные API** [факт, [тарифы](https://platform.2gis.ru/ru/tariffs)]:
  - **Places API** — поиск организаций по широкому ряду признаков; вместе с ним Categories API (рубрики).
  - **Routing API** — маршруты для транспорта и пешеходов, в том числе общественного транспорта.
  - **Distance Matrix API** — расстояние и время между точками.
- **Демо-ключ — бесплатно на 30 дней.** [факт, [тарифы](https://platform.2gis.ru/ru/tariffs)]
  - Выдаётся в кабинете platform.2gis.ru; с ним можно попробовать все публичные сервисы. [факт, [помощь 2ГИС](https://help.2gis.ru/question/produkty-2gis-dlya-biznesa-i-razrabotchikov)]
  - **Лимит демо-ключа — 1 000 единиц на сервис на весь срок, не в сутки.** Это Places, Categories, Routing, Distance Matrix и др.; у Map Tiles — 500 000. [факт, [тарифы и правила тарификации](https://docs.2gis.com/ru/platform-manager/subscription/pricing)]
  - Выдаётся один раз, действует месяц; с мобильным SDK не работает. После покупки подписки его можно перевести в рабочий. [факт, [ключи доступа](https://docs.2gis.com/en/platform-manager/subscription/keys) — по выдаче поиска]
  - Для студентов и некоммерческих проектов — отдельный демо-ключ «на ограниченный период». [факт, там же]
- **Цены — подписка на месяц** (на год −10%). [факт, калькулятор на [странице тарифов](https://platform.2gis.ru/ru/tariffs), 25.10]
  - **Что считается единицей** [факт, [правила тарификации](https://docs.2gis.com/ru/platform-manager/subscription/pricing)]:
    - Places — успешный запрос;
    - Routing — маршрут на каждую пару точек;
    - Distance Matrix — каждая пара «откуда × куда»: 2 × 3 точки = 6 единиц.
  - Пакеты в месяц одинаковы для Places, Categories, Routing и Distance Matrix: 10 тыс. — 6 700 ₽, 30 тыс. — 15 000 ₽, 50 тыс. — 20 000 ₽, 100 тыс. — 30 000 ₽. [факт, там же]
  - Скорость — до 600 единиц в минуту на сервис. [факт, там же]
  - Places API — **6 700 ₽ / мес за 10 000 запросов**.
  - Routing API — **6 700 ₽ / мес за 10 000 ответов**.
  - Distance Matrix API — **6 700 ₽ / мес за 10 000 ответов**.
  - Оплата картой или по счёту.
  - Готовые наборы: «Строить маршруты» (4 сервиса) — от 28 400 ₽; «Показать бизнес на карте» — от 21 700 ₽.
- **Условия справочного API (Places)** [факт, [оферта](https://law.2gis.ru/webapi-offer)]:
  - «Кэширование Продуктов не предусмотрено»;
  - нельзя «извлекать, сохранять полученные… Продукты и информацию из них» (п. 3.1);
  - показывать в своём приложении со ссылкой «2ГИС» (п. 2.5.2, 2.10).
- Бесплатный API карты — только некоммерческий: платные проекты запрещены (п. 3.3, 3.4). [факт, [правила API](https://law.2gis.ru/api-rules)]

## Google Maps Platform

Цены — за 1 000 запросов; бесплатный лимит — в месяц, для каждого SKU свой. [факт, [цены](https://developers.google.com/maps/billing-and-pricing/pricing), обновлено 23.10.2026]

| Что | SKU | Бесплатно в месяц | Цена за 1 000 |
|---|---|---|---|
| Поиск рядом или по тексту: тип и координаты | Nearby / Text Search Pro | 5 000 | $32 |
| + часы работы, рейтинг, уровень цен | … Enterprise | 1 000 | $35 |
| + отзывы, вегетарианское меню, пиво, терраса, с собакой, с детьми | … Enterprise + Atmosphere | 1 000 | $40 |
| Детали места | Place Details Essentials / Pro / Enterprise / +Atmosphere | 10 000 / 5 000 / 1 000 / 1 000 | $5 / $17 / $20 / $25 |
| Маршрут без пробок, до 10 точек | Compute Routes Essentials | 10 000 | $5 |
| Маршрут с пробками (`TRAFFIC_AWARE`, `TRAFFIC_AWARE_OPTIMAL`) | Compute Routes Pro | 5 000 | $10 |
| Матрица (за элемент: старты × финиши) | Compute Route Matrix Essentials / Pro | 10 000 / 5 000 | $5 / $10 |

- **SKU выбирается по запрошенным полям,** берётся самый дорогой из них. [факт, [поля по SKU](https://developers.google.com/maps/billing-and-pricing/sku-details), [Routes: биллинг](https://developers.google.com/maps/documentation/routes/usage-and-billing)]
- **Как получить ключ:** проект в Google Cloud → платёжный аккаунт с картой → включить Places API (New) и Routes API → создать ключ. Без платёжного аккаунта не работает. [факт, [биллинг](https://developers.google.cn/maps/billing-and-pricing/billing?hl=en)]
- **Россия:** в список запрещённых территорий не входит; там Крым, ДНР, ЛНР и др. [факт по копии страницы от 21.03.2022, [список](https://cloud.google.com/maps-platform/terms/other/maps-prohibited-territory)] Примут ли российскую карту — не проверено; скорее всего нужна иностранная. [вывод]
- **Условия:** нельзя «pre-fetch, cache, or store Places API content», кроме place ID — его хранить можно бессрочно. [факт, [политики Places](https://developers.google.com/maps/documentation/places/web-service/policies)]
  - Вне карты Google — с логотипом Google.
  - Для отзывов и фото — с указанием автора.

## Что это значит для нас [вывод]

1. **Хранить данные карт у себя по стандартным условиям нельзя ни у кого из трёх.**
   - Это касается базы фактов, пакетов городов и данных в репозитории для жюри.
   - Можно запрашивать вживую и показывать с указанием источника.
   - Яндекс — только на своей карте; Google — на своей карте или с логотипом.
   - Условия маршрутов отдельно не проверял — вероятно, такие же.
   - Это расходится с тем, как D35 описывает «можно брать: места, рейтинги, маршруты»: брать можно только вживую, без хранения. Если у организаторов особая договорённость с картами — нужен её текст.
2. **Поэтому разумная схема:**
   - **В пакеты и базу — открытые данные:** OSM (ODbL, с указанием источника) и свой маршрутизатор по OSM — без пробок.
   - **Карты — живой запрос во время поиска,** например «итальянский ресторан рядом» или «время до X с пробками». Показ — с источником, в базу не пишем; бейдж «по данным 2ГИС / Google, сейчас».
   - **Без ключа** (у жюри его не будет — секреты в репозиторий не кладём) функция мягко откатывается на OSM. Пометка: «по картам не проверено».
3. **Что брать на хакатон:**
   - **2ГИС — демо-ключ, бесплатно на 30 дней.** Покрывает срок до финала 30.10, есть общественный транспорт, российская оплата, если понадобится.
   - **Google — бесплатные лимиты в месяц:** 1 000–5 000 запросов на SKU хватит для показа. Нужна карта для платёжного аккаунта.
   - **Яндекс** — бесплатного варианта для поиска и маршрутов нет, лицензия от ~195–226 тыс. ₽ в год на каждый API. Не берём.
4. **Ручная добыча (D33):** человек проверяет единичные факты для отелей показа — обычная практика. Массовое копирование справочника запрещают и пользовательские соглашения карт. Например, у 2ГИС: «извлекать из баз данных… любые материалы» нельзя ([§5.1.4](https://law.2gis.ru/platform-manager)), а это соглашение о кабинете разработчика.

Не юридическая консультация. Условия меняются — перед использованием перечитать по ссылкам.

## Решение — D37 (25.10)

**Поставщик — 2ГИС:** Places, Routing, Distance Matrix. Ключ и подписку заводит пользователь, начинаем с демо-ключа.

Пользователь: в прототипе храним у себя данные карт, которые не нужно запрашивать на каждый запрос, и общие; если проект пойдёт дальше — пересмотр. Правила хранения — в D37: отдельный файл пакета, паспорт, `commercial_ok: false`; отзывы и фото не храним; Google place ID — без ограничений.

**Дешёвый поиск кандидатов у Google** [факт, [Text Search](https://developers.google.com/maps/documentation/places/web-service/text-search)]:
- SKU «Text Search Essentials (IDs Only)» — бесплатно и без лимита. Его включает маска полей только из `places.id`, `places.name` (это `places/PLACE_ID`, не название), `nextPageToken` и служебных полей.
- Фильтр по одному типу (`includedType` + `strictTypeFiltering`) и прямоугольник `locationRestriction` (только для категорийных запросов).
- До 20 мест на страницу и не больше 60 на запрос.

Это позволяет даром узнать, какие места нужного типа есть в квадрате вокруг отеля, и хранить их ID законно. Платные детали (часы, рейтинг) докупаются только для нужных мест. [вывод]

**Объём** [вывод]: 7011 отелей стоят плотными группами. Запросы лучше вести по ячейкам сетки, а не по каждому отелю, — так их в разы меньше.
