# О!знаю — команда vaibovovka

Ostrovok Hackathon 2026, трек «О!дин шаг до идеального отеля».

Гость пишет пожелание обычным текстом — например, «тихий номер с видом на закат недалеко от моря». Система подбирает номера и по каждому условию показывает «Подходит», «Нужно уточнить» или «Не подходит», а также откуда это известно. Мы знаем об отелях то, чего нет в карточке: считаем по геоданным, спрашиваем отельера, собираем из открытых источников и карт. У каждого факта есть паспорт: источник, способ получения, дата, уверенность.

Города: Москва и Большой Сочи — полная глубина; ещё 6 городов — автоматический слой.

> Быстрый старт, переменные окружения, данные и ссылка на видео появятся здесь к сдаче (29.10, 10:00 МСК).

## Структура

| Папка | Что | Владелец |
|---|---|---|
| `app/` | API, раздача интерфейса, `/health` | лид |
| `core/` | Факты, спецификации, цепочка рецептов, поиск | лид |
| `connectors/` | Готовые данные | Сева |
| `calculators/` | Вычисляемые характеристики | Сева, Лера, лид |
| `agents/` | LLM: запрос, отельер, объяснения | Данил |
| `specs/` | Спецификации характеристик | лид |
| `pipeline/`, `packs/` | Сборка и пакеты городов | Сева |
| `ui/` | Интерфейс | Андрей |
| `tests/` | Тесты, метрики | Лера, все |

## Разработка

```bash
uv lock                                              # один раз: зафиксировать версии (uv.lock в репозиторий)
uv sync --extra api --extra llm --group dev          # окружение приложения
uv sync --extra api --extra builder --group dev      # + сборка пакетов городов (Сева, Лера, лид)
uv run uvicorn app.main:app --port 8080              # API на заглушках из фактов v9
uv run pytest                                        # тесты
uv run ruff check . && uv run ruff format --check .  # стиль
```

Контракты (факт, плагин, запрос, API, пакет города) — `docs/design/contracts.md`.

## Как работаем

- Ветка `имя/задача`, маленькие PR в `main`, ревью лида. Напрямую в `main` не пушим.
- Синк утром и вечером.
