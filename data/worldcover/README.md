# Вырезки WorldCover для пробного расчёта

Здесь лежат **вырезанные** тайлы ESA WorldCover 2021 v200 — только окно с отелями Сочи и Москвы.
Полный тайл 3°×3° — это 36 000×36 000 пикселей и 150–250 МБ на файл, в репозиторий такое не
положить. Вырезано `pipeline/fetch_worldcover.py` из облачных COG (GDAL `/vsicurl/` читает
только нужный диапазон, целиком ничего не скачивается).

| Файл | Пикселей | Размер | Что покрывает |
|---|---|---|---|
| `ESA_WorldCover_10m_2021_v200_N42E039_Map.tif` | 12 621 × 7 612 | 1,2 МБ | Большой Сочи, bbox 39,259…40,311 × 43,345…43,979 |
| `ESA_WorldCover_10m_2021_v200_N54E036_Map.tif` | 7 378 × 6 588 | 3,3 МБ | Москва, 37,272…37,887 × 55,447…55,996 |

Имя файла — каноническое (как у ESA), поэтому калькуляторы находят его без правок: они ищут
`ESA_WorldCover_10m_2021_v200_N{широта}E{долгота}_Map.tif` в `<DATA_DIR>/worldcover` или
`WORLDCOVER_DIR`. Это вырезка, а не полный тайл: круг или точка за краем окна дают «нет тайла»
(`worldcover_tile_missing:…:outside_window`), а не «покров размечен меньше 99%» и не «класс 0».

**Лицензия:** ESA WorldCover, CC BY 4.0 — указание источника обязательно, коммерческое
использование разрешено. Изменение — вырезка окна, значения пикселей не менялись.

## Зачем

Без тайлов пробный расчёт новой характеристики из текста (`agents.specgen`) отвечает
«неизвестно — нет тайла» у всех отелей. С тайлами (из корня репозитория, с группой `builder`):

```bash
python -m agents.specgen "доля застройки в 300 м" --trial --city sochi
# "statuses": {"computed": 11}, "coverage": 1.0
```

Значения по Сочи: Radisson 88,2% застройки в 300 м, «Коралл» 66,7%, Mantera 73,1%.
«Доля воды в 500 м» считается от всей размеченной площади круга: Radisson 31,8%, Mantera 29,0%.

## В образ приложения не кладём (D41 п. 5)

Пробный расчёт по покрову — **вне контейнера**. В образе только группы `api` и `llm`, а
numpy, rasterio, shapely и pyproj — в `builder`; одной правки `.dockerignore` для работы в
контейнере мало. Без геобиблиотек калькуляторы `env.landcover_share` и E03 отвечают
«неизвестно» с причиной `geo_libs_missing`, а не падают. Если пробный расчёт понадобится в
контейнере, нужно отдельное решение: геобиблиотеки в образ, ограничение радиуса и числа отелей,
замер холодной сборки против лимита 10 минут.

## Пересобрать окно

```bash
python -m pipeline.fetch_worldcover --city sochi
python -m pipeline.fetch_worldcover --city moscow --margin 0.1
python -m pipeline.fetch_worldcover --city sochi --check   # только посчитать bbox
```

`--margin` — запас вокруг отелей в градусах (по умолчанию 0,05° ≈ 5,5 км). Окно строится по
отелям когорты v9: отели каталога за его краем (13 в Сочи, 81 в Москве) получат «нет тайла» —
при расширении когорты прогон надо повторить. Морские ячейки B02 южнее и западнее окна
проверяются на воду по карте ячеек (`marine_mapping`), а не по вырезке. Новые вырезки
помечаются тегами GeoTIFF `CROPPED_FROM` и `CROP_BBOX`.

`.gitignore` исключает `*.tif`; эти два файла добавлены в git принудительно.
